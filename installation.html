Installez l'application

Retrouvez facilement votre espace d'administration. L'installation est facultative : vous pouvez aussi utiliser le site dans votre navigateur.

Sur iPhone ou iPad

  1. Ouvrez l'application dans Safari.
  2. Appuyez sur le bouton de partage de Safari.
  3. Choisissez « Sur l'écran d'accueil » (ou « Ajouter à l'écran d'accueil »), puis « Ajouter ».
  4. Retrouvez l'icône Administration sur votre écran d'accueil.

Sur Android

  1. Ouvrez l'application dans Chrome.
  2. Ouvrez le menu ⋮ du navigateur.
  3. Choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».
  4. Confirmez, puis ouvrez l'application depuis votre écran d'accueil.

Sur ordinateur

  1. Ouvrez l'application dans Chrome ou Edge.
  2. Si le navigateur propose « Installer », cliquez dessus.
  3. Sinon, conservez le site dans vos favoris et utilisez-le normalement.
